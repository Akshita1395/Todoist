# Todoist Homepage Redesign

A conceptual frontend redesign of the Todoist homepage created as part of the Acdyon Technologies Frontend Challenge.

## 🌐 Live Demo

https://todoisthomepage.vercel.app/

## 📌 About the Project

This project redesigns the Todoist homepage with a simple and calm productivity-focused design.

The main idea is:

> Get your head clear.

The homepage focuses on helping users organize their daily tasks and stay focused on what matters.

## ✨ Features

- Clean and responsive homepage
- Simple navigation bar
- Hero section with clear call-to-action
- Today's task preview
- Capture tasks, ideas, and reminders section
- Daily focus section
- Progress section
- Interview/productivity section
- Working task checkbox interaction
- Responsive design for mobile and desktop
- Conceptual redesign disclaimer

## 🛠️ Tech Stack

- Next.js
- React
- Tailwind CSS
- TypeScript

## 📱 Responsive Design

The website is designed to work on:

- Desktop screens
- Mobile screens
- 390px mobile width
- 1440px desktop width

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/Akshita1395/Todoist.git
```

Go into the project:

```bash
cd Todoist
```

Install dependencies:

```bash
pnpm install
```

Run the development server:

```bash
pnpm dev
```

Open:

http://localhost:3000

## 📂 Project Structure
