# DECISIONS

> **Disclaimer:** This project is an independent conceptual homepage redesign created for a frontend assignment. It is **not** an official Todoist website and is not affiliated with or endorsed by Todoist.

---

## 1. Why this approach?

I chose to redesign the homepage around the main theme: **"Get your head clear."** 

The core goal was to create a productivity landing page that feels calm, friendly, and easy to use. Instead of overwhelming visitors with complex features, the website focuses on helping users organize their daily thoughts into a simple plan for today.

I structured the homepage using a clean layout:
- **Navbar:** Simple logo and navigation links.
- **Hero Section:** Clear headline, friendly subtitle, and an interactive task card showing the product in action.
- **Capture Everything:** Explaining how tasks, ideas, and reminders flow into one organized inbox.
- **Focus on Today:** Showing a clear daily schedule (Morning, Afternoon, Evening).
- **Make Progress:** Visualizing simple weekly task completion.
- **Final Call to Action & Footer:** Encouraging users to get started, with clear assignment disclaimers.

I chose a **frontend-only approach** because this assignment focuses on landing page design and user experience. It does not require a backend server, database, user login system, or real Todoist data. 

I used **Next.js, React, and Tailwind CSS** because they allowed me to build a clean, responsive website quickly while keeping the code beginner-friendly and easy to explain.

---

## 2. Trade-off made because of the time limit

Because of the time limit for this assignment, I focused on creating a polished homepage experience rather than building a full productivity web application.

The task items shown on the page are **demo example tasks**. There is no real database, user authentication system, or connection to Todoist servers. 

If I had more development time, I would:
- Connect a real backend database to save user tasks.
- Build user account registration and login functionality.
- Allow users to add, edit, and delete their own custom task lists.
- Add drag-and-drop task reordering and calendar reminders.

---

## 3. Use of AI tools

During this project, I used AI tools as a pair-programming assistant to:
- Brainstorm the homepage layout and content structure.
- Help write and refine frontend React components and CSS styling.
- Ensure the layout works properly on mobile (390px) and desktop (1440px) screens.
- Debug development issues and clean up the codebase.

I reviewed the generated code, tested the website locally in the browser, checked the mobile layout, tested the task checkbox interaction, and reviewed the final design before deployment. 

My goal was to use modern AI assistance responsibly to deliver a clean, responsive, and well-structured project that I can understand, explain, and defend in a fresher interview.
